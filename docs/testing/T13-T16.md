## How to re-run

1. Start PostgreSQL and the backend (`scripts\start-dev.bat`) and load the demo data (`scripts\load-demo-data.bat`).
2. From `frontend/`: `npm ci`, then `npm run test:ui`.
   The test uses Microsoft Edge by default; set `CHROME_PATH` to use another Chromium browser.
3. The backend allows the test origin `http://localhost:3010` by default (`CORS_ORIGIN`).

The attendance PIN flow (open PIN, wrong PIN, correct PIN, roster refresh, manual status, close) is covered by the backend integration tests (`npm test` in `backend/`) and was also checked end to end in two browsers on 21/11/2026.
